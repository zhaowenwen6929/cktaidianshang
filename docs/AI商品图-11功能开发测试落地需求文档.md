## 3. 通用界面与交互（11 功能共用）

- 页面结构：左侧导航 -> 工具列表 -> 配置面板 -> 结果面板 -> 右侧创作记录。
- 通用配置区块：
1. `upload-main` 上传商品图（支持 `JPG/PNG/WebP`）
2. `creation-mode` 创作模式（普通/高级/中文增强等，按功能差异）
3. `advanced-settings` 高级设置（按功能差异）
4. `supplement` 细节补充（按功能差异）
5. `upload-reference` 参考图（仅部分功能）
- 任务状态：`queued` -> `generating` -> `completed`。
- 结果状态：`queued/generating/ready/failed`。
- 右侧创作记录行为：
1. 按日期分组
2. 点击任务恢复快照（主图、参考图、补充说明、当前任务上下文）
3. 收起时展示进行中徽标

## 6. 开发落地规则（必须对齐）

1. 任务写入：提交生成后必须同时写入 `resultItemsByTool` 与 `taskRecordsByTool`。
2. 状态流转：`queued -> generating -> completed`，完成条件为 `successCount + failCount >= totalCount`。
3. 快照恢复：点击右侧任务卡必须恢复 `mainUploads/referenceUploads/videoUploads/supplementValue`。
4. 工具隔离：右侧创作记录仅展示当前工具记录，不跨工具混排。
5. 失败处理：删除失败项/取消排队项后，任务计数和封面图同步修正。
