# 【视频创作】视频背景移除-需求文档

## 需求目标
用户输入：

1. 上传 1 条待处理视频

系统输出：

+ 输出 1 条主体与背景分离后的视频结果
+ 尽量完整保留人物、商品、发丝、透明边缘和细小结构
+ 保持帧间边缘稳定，便于后续换背景或二次剪辑

## 核心逻辑
视频背景移除是“主体抠出与背景分离”能力，不是视频重生成能力。当前真实执行链路如下：

1. 读取原视频主体内容
2. 识别人物、商品或其他主体边界
3. 对原视频背景做分离处理
4. 输出 1 条适合后续换背景或二次剪辑的视频结果

## 使用流程
1. 上传视频（`upload-video`）
2. 生成

## 端到端使用流程
1. 用户上传 1 条视频。
2. 系统识别主体边缘和背景区域。
3. 系统执行视频抠像与背景分离处理。
4. 返回 1 条处理结果视频。

## 功能基础说明

### 1.1 功能定位

- 功能名称：`视频背景移除`
- 工具 Key：`video-remove-bg`
- 所属一级分组：`视频创作`
- 能力定位：对视频中的人物、商品或主体执行背景移除处理

### 1.2 当前真实页面结构

- `creationModeConfigKey`：`video-processing`
- `sectionOrder`：`["upload-video"]`
- 上传区：
  - 视频：最多 `1` 条，必填
- 当前页面不展示补充说明输入框
- 当前页面不展示模式切换、蒙版绘制、目标语言或创作模式切换 UI

补充说明：

+ 配置层存在 `video-processing` 的 `showSupplement=true` 与普通/高级模式定义，但当前页面未挂载对应区块
+ 文档应以“上传即处理”的真实页面形态为准

## 2. 处理原则

### 2.1 当前真实输入参数

```json
{
  "videoRemoveBgFields": {}
}
```

说明：

+ 当前页面除上传视频外，没有额外显式参数
+ 若后续开放补充说明、边缘精度、输出背景等参数，应在文档中新增对应区块，不应提前按现有页面已支持来描述

### 2.2 质量要求

1. 主体轮廓完整
2. 发丝、透明材质和细小边缘尽量保留自然
3. 帧间边缘稳定，避免抖动与闪烁
4. 结果适合后续换背景或二次剪辑

## 3. 推荐处理指令骨架

```text
你是一位视频主体分离与背景移除专家。

任务目标：基于用户上传的视频，完整保留主体内容并移除背景，输出 1 条处理后视频。

原视频约束：
1. 保持原视频比例、主体动作和镜头节奏不变。
2. 不破坏人物、商品或核心主体结构。

质量要求：
1. 主体边缘干净自然。
2. 发丝、透明区域、局部细节尽量保留。
3. 帧间边缘与抠像结果稳定，便于后续换背景或二次剪辑。
```

## 4. 与相邻功能的边界

### 4.1 与 `video-watermark` 的边界

- `video-remove-bg`：处理主体与背景的整体分离关系
- `video-watermark`：处理局部水印、字幕、角标清除

### 4.2 与 `video-clarify` 的边界

- `video-remove-bg`：核心是抠像与背景移除
- `video-clarify`：核心是画质增强

## 6. 当前版本结论

当前 `video-remove-bg` 已落地的真实能力可以定义为：

+ 上传 1 条视频
+ 系统直接执行背景移除处理
+ 输出 1 条处理结果视频

当前 `video-remove-bg` 尚未落地的能力也应明确标注：

+ 当前页面未开放补充说明输入
+ 当前页面未开放显式普通/高级模式切换
+ 当前页面未开放手动蒙版、边缘精修或输出背景类型选择
