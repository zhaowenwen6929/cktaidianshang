# 【视频创作】视频去水印字幕-需求文档

## 需求目标
用户输入：

1. 上传 1 条待处理视频
2. 选择处理模式（自动 / 手动）
3. 自动模式下选择识别目标（智能识别 / 水印 / 字幕）
4. 手动模式下绘制蒙版区域

系统输出：

+ 输出 1 条去除水印、字幕或角标后的处理结果视频
+ 保持人物、商品、背景纹理和画面连续性自然
+ 尽量减少修补痕迹、局部涂抹感和帧间闪烁

## 核心逻辑
视频去水印字幕是“局部内容清除与补全”能力，不是视频重制能力。当前执行链路如下：

1. 读取原视频并保留原视频比例
2. 根据模式判断是自动识别目标区域，还是使用手工蒙版区域
3. 对目标区域执行清除与内容补全
4. 输出 1 条处理后视频

## 使用流程
1. 上传视频（`upload-video`）
2. 选择模式（`mode-choice`）
3. 若为手动模式，绘制蒙版（`mask-draw`）
4. 生成

## 端到端使用流程
1. 用户上传 1 条视频。
2. 用户选择 `自动` 或 `手动` 模式。
3. 若选择 `自动`，继续指定 `智能识别 / 水印 / 字幕`。
4. 若选择 `手动`，基于视频封面帧绘制要处理的区域。
5. 系统执行区域识别、清除与补全，返回 1 条处理结果视频。

## 功能基础说明

### 1.1 功能定位

- 功能名称：`视频去水印字幕`
- 工具 Key：`video-watermark`
- 所属一级分组：`视频创作`
- 能力定位：去除视频中的水印、字幕或角标，并尽量保持画面自然完整

### 1.2 当前真实页面结构

- `creationModeConfigKey`：`video-processing`
- `sectionOrder`：`["upload-video", "mode-choice", "mask-draw"]`
- 上传区：
  - 视频：最多 `1` 条，必填
- 当前页面不展示补充说明输入框
- 当前页面不展示单独的普通/高级模式切换 UI

补充说明：

+ `video-processing` 配置层存在 `showSupplement=true` 和 `普通模式 / 高级模式`，但当前 `video-watermark` 页面未挂载 `supplement` 与 `creation-mode` 区
+ `mask-draw` 仅在 `手动` 模式下显示

## 2. 处理模式

### 2.1 字段与可选值

```json
{
  "videoWatermarkFields": {
    "videoWatermarkModeKey": ["smart", "manual"],
    "videoWatermarkMode": ["自动识别", "手动绘制蒙版"],
    "videoWatermarkAutoTarget": ["智能识别", "水印", "字幕"],
    "videoWatermarkMaskDataUrl": "仅手动模式下写入"
  }
}
```

说明：

+ `smart` 模式下需要记录自动识别目标
+ `manual` 模式下需要记录蒙版数据
+ 手动模式仅支持单个视频

### 2.2 自动模式

1. `智能识别`
   由系统自动判断应清除的水印、字幕或角标区域。
2. `水印`
   优先针对平台水印、角标、logo 类区域处理。
3. `字幕`
   优先针对底部或画面中的字幕文本区域处理。

### 2.3 手动模式

1. 用户基于视频封面帧绘制蒙版区域
2. 系统按蒙版区域执行清除与补全
3. 当前仅支持单个视频输入；若非单个视频，前端会阻止进入手动模式

## 3. 最终处理原则

视频去水印字幕最终处理指令至少应包含以下信息层：

1. 任务目标：清除水印、字幕或角标
2. 原视频约束：保持原视频比例、主体动作与节奏
3. 模式信息：自动 / 手动
4. 目标区域信息：自动目标或手工蒙版
5. 质量约束：修补自然、背景连续、人物主体完整

### 3.1 推荐处理指令骨架

```text
你是一位视频局部修复与内容清除专家。

任务目标：基于用户上传的视频，去除指定的水印、字幕或角标内容，并输出 1 条处理后视频。

原视频约束：
1. 保持原视频比例、主体动作、镜头节奏不变。
2. 不得破坏人物、商品和主要背景结构。

处理模式：
当前模式={videoWatermarkMode}；
自动识别目标={videoWatermarkAutoTarget}；
手动蒙版区域={videoWatermarkMaskDataUrl}。

质量要求：
1. 清除区域要尽量完整。
2. 背景纹理、边缘过渡和帧间连续性需自然稳定。
3. 避免明显修补痕迹、拖影、结构断裂或局部闪烁。
```

## 4. 与相邻功能的边界

### 4.1 与 `video-clarify` 的边界

- `video-watermark`：核心是去除指定局部内容
- `video-clarify`：核心是提升整体清晰度

### 4.2 与 `video-remove-bg` 的边界

- `video-watermark`：处理局部覆盖物
- `video-remove-bg`：分离主体与整体背景

## 6. 当前版本结论

当前 `video-watermark` 已落地的真实能力可以定义为：

+ 上传 1 条视频
+ 选择自动或手动处理模式
+ 自动模式下指定 `智能识别 / 水印 / 字幕`
+ 手动模式下绘制蒙版区域
+ 输出 1 条去水印或去字幕后的视频

当前 `video-watermark` 尚未落地的能力也应明确标注：

+ 当前页面未开放补充说明输入
+ 当前页面未开放显式普通/高级模式切换
+ 当前不应被表述为视频翻译、视频增强或整段视频重制能力
