# AI功能积分计算规则（按一键白底图口径补齐）

## 1. 统一计费口径

- 单位积分：`unitCreditCost`
- 出图数量：`count`
- 主图上传数：`sourceCount`
- 参考图上传数：`referenceCount`

通用总积分公式：

- 常规图片类：`总积分 = sourceCount * unitCreditCost * count`
- 套图/视频类特殊：`总积分 = 特殊输出数量 * unitCreditCost`

其中：

- `set-main / set-aplus / set-fashion`：`特殊输出数量 = count`
- `set-replica / video-print-extend`：`特殊输出数量 = sourceCount * referenceCount * count`
- 视频工具（video-*）：`特殊输出数量 = count`，`unitCreditCost`来自视频维度定价或模式单价

补充：每次提交生成还会扣固定存储容量 `24MB`（与积分并行扣减）。

---

## 2. 一键白底图（基准规则）

- 普通模式：`5积分/张`
- 高级模式：按分辨率计费
1. `1K = 10积分/张`
2. `2K = 15积分/张`
3. `4K = 20积分/张`

白底图总积分：`上传张数 * 单位积分 * 出图数量`

## 3. 已在代码中明确的功能积分规则

- 一键白底图：普通`5`；高级`1K=10/2K=15/4K=20`
- 一键买家秀：走默认档（普通`1`；高级`1K=2/2K=3/4K=5`）
- 一键场景图：普通`5`；高级`1K=10/2K=15/4K=20`；中文增强`10`
- 一键细节图：走默认档（普通`1`；高级`1K=2/2K=3/4K=5`）
- 一键卖点图：走默认档（普通`1`；高级`1K=2/2K=3/4K=5`）
- 一键代言图：普通`5`；高级`1K=10/2K=15/4K=20`；中文增强`10`
- 一键三视角：普通`2`；高级`1K=4/2K=6/4K=8`
- 产品精修：普通`2`；高级`1K=3/2K=4/4K=6`
- AI换背景：普通`5`；高级`1K=10/2K=15/4K=20`；文本增强`10`
- 图片翻译：高级`1K=10/2K=15/4K=20`；智能模式`1K=20`；中文增强`10`

### 3.2 电商套图

- 电商套图 / A+详情图 / 服饰套图：
1. 普通`5`
2. 高级`1K=10/2K=15/4K=20`
3. 中文增强`15`

- 爆款套图复刻（set-replica）：沿用“代言图档位”
1. 普通`5`
2. 高级`1K=10/2K=15/4K=20`
3. 中文增强`10`

且总积分按：`sourceCount * referenceCount * count * unitCreditCost`

### 3.3 模特图

- 模特试穿：走默认档（普通`1`；高级`1K=2/2K=3/4K=5`）
- 模特调整：普通`5`；高级`1K=10/2K=15/4K=20`；中文增强`10`（固定1张）
- 模特生成：沿用“代言图档位” 普通`5`；高级`1K=10/2K=15/4K=20`；中文增强`10`

### 3.4 图片处理

- 一键抠图：固定`10`
- 去除水印：自动`10`；手动`5`
- 超分提质：`2K=5`，`4K=10`，`8K=20`
- 图片消除：固定`5`
- 提取线稿：清稿`5`；草图/速写`10`；精细素描`15`
- 图片扩图：普通`5`；高级`1K=10/2K=15/4K=20`

### 3.5 POD印花

- 图案裁剪：通用`5`；铁皮画`10`；装饰画`15`
- 印花图提取：固定`5`
- 印花图裂变：当前实现按默认档（普通`1`；高级`1K=2/2K=3/4K=5`）
- 局部改图：固定`5`
- 元素融合：固定`5`；总积分=`融合素材组数 * 5 * 出图数量`
- 多联画：固定`5`；总积分=`上传数 * 出图数 * 5`
- 四方连续图：固定`5`
- 印花尺寸延展：固定`5`；总积分=`上传数 * 比例数 * 出图数 * 5`

### 3.6 视频创作

- 爆款复刻（video-replica）：按维度累加计费
1. 模式：普通`30` / 高级`50`
2. 时长：`4s~15s`从`0`到`44`递增
3. 比例：`0~14`
4. 分辨率：`480p=0`，`720p=18`
5. 有声：`+15`

- 产品视频（video-main）、商品替换（video-replace）：当前按模式基础单价 `1`（480p/720p同价）

## 5. 可执行的最终规则（推荐）

为避免前台出现 1 分、2 分、5 分混用导致预期不一致，建议：

- 将“AI商品图、模特图、POD创作类”的默认档统一提升为白底图档（`5/10/15/20`）
- 保留“工具型处理”差异定价（如抠图10、超分分档、线稿分档）
- 视频类继续使用“维度累加”，但设最低消费不低于白底普通档（可设最低 `5`）

这样可形成三层价格体系：

1. 标准创作档（白底图系）
2. 工具处理档（按算法成本）
3. 视频复合档（按维度累加）
