# AI商品图-模特生成-提示词与配置方案

## 1. 功能目标

`模特生成（model-generate）`用于在无现成模特素材或需要补充基准模特时，按结构化参数快速生成可直接用于后续试穿/换装链路的人像素材。

当前操作由两部分组成：

1. `model-generate-setup`：选择模特类型
2. `model-generate-parameters`：配置人物特征与场景

## 2. 配置落点（代码基线）

- 配置入口：[src/App.tsx](/Users/zhaowenwen/CODEX/CKTAI电商/src/App.tsx)
- 工具分段：
1. `sectionOrder = ["model-generate-setup", "upload-main", "model-generate-parameters", "creation-mode", "upload-reference"]`
2. `creationModeConfigKey = "spoke"`
- 上传约束：
1. 主图 `upload-main.maxCount = 24`
2. 参考图 `upload-reference.maxCount = 1`（可选）

## 3. 操作级提示词

### 3.1 model-generate-setup（模特类型）

操作级基准 prompt：

```text
请基于当前选择的模特类型生成电商可用人物素材，保持单人主体、结构真实、光影自然和商业成片质感；不得出现多余人物、肢体畸形、五官崩坏、服饰穿帮和低清伪影。
```

### 3.2 model-generate-parameters（特征与场景）

操作级基准 prompt：

```text
请严格遵循已选的人物特征与场景参数生成人像，确保性别、年龄、外貌、人设、体型和场景表达一致；人物姿态自然、比例合理、边缘干净，适合电商服饰展示与后续二次编辑。
```

## 6. 字段要求与校验建议

1. 必填校验：`gender/appearance/age/persona/bodyType` 必填，缺失时阻止生成。
2. 可选字段：`scene`、`supplement`、`reference` 可为空。
3. 自由输入支持：`appearance/age/persona/bodyType` 在前端为可输入下拉，非预置值时直接拼入 `补充说明`，并保留对应字段标签。

## 8. 上传模特图处理与交互（开发实现补充）

## 8.1 上传入口与交互

1. 主图上传区支持 `本地上传` 和 `资源库` 两个入口。
2. 支持点击上传和拖拽上传；拖拽进入时显示投放态。
3. 主图上限 `24` 张；达到上限后继续上传会触发 `onAtLimit`。
4. 参考图上限 `1` 张，作为风格/脸型/气质参考，不替代主图。

## 8.2 上传过滤与失败反馈

1. 文件类型仅接受图片（`image/*`）。
2. 敏感图片会被过滤，触发提示：`图片未通过审核请重新上传`。
3. 当超出数量上限或存储容量不足时，触发 `onAtLimit` 统一提示。
4. 上传过程先写入 `loading` 状态，读取完成后切换为 `ready`。

## 8.3 模特图保护区自动处理

1. `model-generate` 主图支持保护区蒙版（`maskDataUrl` + `maskLabel`）。
2. 首次进入编辑/刷新时，根据模特类型自动生成保护区：
3. `real-model`、`mannequin-model` 对应 `服饰保护区`。
4. `wig-model` 对应 `头发保护区`。
5. 保护区由 `createAutoProtectMaskDataUrl(...)` 自动生成，并写回上传项。

## 8.4 保护区编辑交互

1. 每个已上传主图卡片提供“编辑选区/优化选区”按钮。
2. 点击后打开 `MaskEditorModal`，可手动调整保护区。
3. 保存后回写当前图片的 `maskDataUrl`，并同步 `maskLabel`。
4. 卡片支持按压预览蒙版效果（预览态显示被蒙版裁切后的图像）。

## 8.5 模特类型切换联动

1. 在 `model-generate-setup` 切换类型时，系统会联动更新全部主图的保护区标签。
2. 已有主图会按新类型重算自动保护区（仅对 `ready` 且有 `src` 的图片执行）。
3. 联动目标：
4. 切换到 `wig-model`：统一改为头发保护策略。
5. 切换到 `real-model/mannequin-model`：统一改为服饰保护策略。

## 8.6 生成前校验与交互闭环

1. 生成前必填：`gender/appearance/age/persona/bodyType`。
2. 未完善时阻断并提示：`请先完善 AI 模特参数`。
3. 生成成功后写入结果记录并提示：`已生成模特`。
4. 上传主图、参考图、保护区及参数选择会进入任务快照，支持后续复盘和恢复。
