# 【AI商品图】爆款套图复刻-需求文档

## 使用流程
1. 上传参考图（`upload-reference`）
2. 上传商品图（`upload-main`）
3. 阅读生成规则说明（`generation-rule-notice`）
4. 选择创作模式（`creation-mode`：普通/高级/中文增强）
5. 配置高级设置（复刻强度 / 主体一致性 / 背景复杂度）
6. 填写补充说明（`supplement`，可选）
7. 生成

## 端到端使用流程
1. 用户上传参考图（`upload-reference`，最多24张），作为爆款风格、构图、光影、场景语义的学习来源。
2. 用户上传商品图（`upload-main`，最多24张），作为最终复刻结果中必须保持真实一致的商品主体。
3. 系统执行图片理解，识别商品品类、商品细分、参考图风格方向、背景复杂度、适合的复刻强度与主体一致性策略。
4. 系统对每一张参考图分别做信息提取，生成对应的 `sceneDimension / creativeDirection / backgroundComplexity / referenceStyleSummary / referenceKeywords`。
5. 系统再对商品图做品类提取，生成 `productCategory / categorySummary / focusPoints / riskPoints`。
6. 系统触发 AI Assist，回填建议字段，如 `replicaStrength / subjectConsistency / targetMarket`。
7. 用户确认推荐结果，并选择创作模式参数（`modeId / ratio / resolution / count`）。
8. 系统展示“多对多生成规则”，实时计算总结果数与总积分。
9. 用户填写补充说明（可选，可走 AI 润色），补充局部约束，如“突出金属质感”“不要过暗”“不要出现人物”。
10. 系统按 strict 规则组装最终提示词并提交生成。
11. 结果返回后，用户可继续换参考图、换复刻强度、换市场方向做二次生成。

实现要求：

+ 当前代码里 `set-replica` 已落地 `replicaStrength / subjectConsistency / backgroundComplexity` 三个显式高级设置；`productCategory / sceneDimension / creativeDirection / targetMarket` 仍属于提取层或后续扩展字段。
+ `productCategory` 建议来自图片理解链路；若识别失败，回退 `通用品类`。
+ `sceneDimension / creativeDirection / replicaStrength / subjectConsistency / backgroundComplexity / targetMarket` 可先由 AI 推荐，再由用户确认。
+ 当前功能已落地的高级设置建议至少包含 `replicaStrength / subjectConsistency / backgroundComplexity`，其中 `targetMarket` 可后置为联动项或默认推断项。
+ `resolution` 仅在 `advanced` 模式下展示和传值，其他模式为空或不传。
+ `count` 表示“每组 商品图 x 参考图 配对的出图数”，不是总图数。

### 1.4 逐张参考图信息提取与商品图品类提取

因为 `set-replica` 的生成逻辑是“每一张参考图都分别参与生成”，所以不应把所有参考图聚合成一份统一风格结论。正确做法是先对每一张参考图分别提取，再按“参考图 x 商品图”的组合进入最终 Prompt。

#### 1.4.1 逐张参考图提取提示词

```text
请分析当前这 1 张参考图，提取它体现的爆款视觉规律，并输出结构化结果，供后续与商品图组合生成时使用。

输出字段：
1. sceneDimension：整体画面维度，判断更偏无背景、简单背景、产品场景、纯色背景、纯色渐变还是图片边框。
2. creativeDirection：整体风格方向，判断更偏简约清新、高级质感、活泼吸睛、复古怀旧、场景写实、科技未来或国风古韵。
3. backgroundComplexity：背景复杂度，判断更偏低复杂、中等复杂还是高复杂。
4. referenceStyleSummary：用一句话总结这张参考图的视觉语言、商业气质和画面节奏。
5. referenceKeywords：提炼 5 到 10 个关键词，描述构图、光影、色调、道具、节奏和商业表达。

要求：
- 优先提炼“能复用到商品图上的视觉规律”，不要写空泛审美形容词。
- 只分析当前这 1 张参考图，不要混入其他参考图信息。
- 输出结果将直接用于“当前参考图 x 商品图”的单次提示词拼装。
```

#### 1.4.2 商品图品类提取提示词

```text
请分析用户上传的商品图，识别商品品类、子类目和最关键的结构特征，并输出结构化结果。

输出字段：
1. productCategory：归一后的商品品类，如服饰类、鞋靴类、箱包类、珠宝饰品类、美妆个护类、食品饮料类、家居百货类、家电数码类、家具大件类、母婴玩具类、汽配五金类、通用品类。
2. categorySummary：一句话概括商品的主要属性、材质、用途和可视化重点。
3. focusPoints：提炼 3 到 5 个必须保真的商品重点，如版型、鞋底结构、包装、接口、五金、材质反光、使用关系等。
4. riskPoints：识别可能在复刻中被破坏的风险点，如结构失真、比例错乱、包装文字丢失、佩戴关系错误等。

要求：
- 只根据商品图本身判断，不要依赖用户主观品类标签。
- 优先输出可用于后续复刻约束的结构特征，不要只给模糊分类名。
- 如果识别不确定，回退到 `通用品类`，并在 `categorySummary` 里说明不确定原因。
```

#### 1.4.3 提取结果在拼装中的使用原则

- 每张参考图各自产生一份提取结果：`sceneDimension / creativeDirection / backgroundComplexity / referenceStyleSummary / referenceKeywords`
- 商品图提取结果负责生成 `productCategory / categorySummary / focusPoints / riskPoints`
- 最终生成按“参考图 i + 商品图 j”的配对关系逐条拼装 Prompt
- `replicaStrength / subjectConsistency / targetMarket` 作为可调控制项，和该条参考图提取结果、商品图提取结果一起进入最终 Prompt
- 不需要把多张参考图汇总成统一结论，而是保留“每张参考图一份提取结果”

## 1. 功能基础说明

## 2.1 `ruleLevel` 多规则使用逻辑
适用场景：一个平台可能同时命中“平台规则 + 图位规则 + 品类规则 + 市场规则”。

### 2.1.1 规则定位
+ `ruleLevel=A`：高优先级硬约束，不可被低级规则覆盖。
+ `ruleLevel=B`：常规约束，可被 A 覆盖。
+ `ruleLevel=C`：补充约束，可被 A/B 覆盖，且可在 token 紧张时优先裁剪。

### 2.1.2 组装顺序（强制）
1. 合并所有命中规则的 `required`（去重后全部保留）。
2. 合并所有命中规则的 `forbidden`（去重后全部保留）。
3. `prompt` 按优先级拼接：`A -> B -> C`。
4. 若提示词长度超限，仅从低优先级描述裁剪：先裁 `C.prompt`，再裁 `B.prompt`；`A.prompt`、`required`、`forbidden` 不裁。

### 2.1.3 冲突处理（强制）
+ 若高低级规则存在冲突，按优先级覆盖：`A > B > C`。
+ 若“风格复刻”与“商品真实性”冲突，永远优先保真。
+ 若平台主图规则与本功能定位冲突，优先将图位降级为“附图/内容图”。

## 拼装规则

### 拼装顺序
1. `task`（任务目标）
2. `referenceSummary`（当前参考图提取结果）
3. `categorySummary`（商品图品类结果）
4. `platform`（平台约束）
5. `category`（品类约束）
6. `dimension`（维度约束）
7. `direction`（风格方向）
8. `params`（高级设置参数行）
9. `optionValuePrompts`（选项扩展约束）
10. `usageSlot`（图位限制）
11. `universalNegative`（通用负向约束）
12. `universalQuality`（通用质量要求）
13. `outputSpec`（输出规格）
14. `supplement`（补充要求，可选）

### 通用负向约束
```json
通用负向约束：
1. 严禁改变商品主体外观、结构、颜色、包装信息和SKU含义，不得把商品替换成其他款式或虚构新版本。
2. 严禁直接复制参考图中的侵权Logo、水印、二维码、人物肖像、品牌元素、文字排版或受保护视觉素材。
```
