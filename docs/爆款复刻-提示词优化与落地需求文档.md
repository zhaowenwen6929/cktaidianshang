# 爆款复刻-提示词优化与落地需求文档

> 更新时间：2026-05-08
> 适用功能：`video-replica`（爆款复刻）

## 1. 需求目标

用户输入：

1. 上传 1 条参考视频（2~15s）
2. 上传 1~5 张同一商品多视角图片
3. 选择创作模式（普通/高级）与参数（时长、比例、分辨率、音频）
4. 补充视频描述

系统输出：

- 先提取参考视频中的可迁移爆款逻辑（镜头、节奏、卖点推进）
- 再结合用户商品多视角信息完成迁移复刻
- 输出 1 条可投放的商品爆款复刻视频

## 2. 核心逻辑（优化后）

`video-replica` 的最终提示词必须由系统拼装，不直接使用用户原始输入。执行链路如下：

1. 参考视频提词：直接输出一段可拼装的参考视频方法提示词
2. 商品一致性约束：绑定用户上传商品图的真实结构与材质
3. 统一质量约束：直接使用最优效果所需的高标准成片约束
4. 用户补充融合：在硬约束不被破坏前提下吸收补充描述
5. 参数注入：模式标签、时长、比例、分辨率、音频写入最终 prompt

## 3. 参考视频提词 Prompt（中间能力）

建议作为中间能力（可用于后端拆阶段执行）。主方案不输出 JSON，直接输出一段可拼装到最终 prompt 的提示词段。

```text
你是一位短视频爆款镜头语言分析师。
请基于输入参考视频提取“可迁移的爆款表达方法”，并直接输出一段可拼装到最终生成提示词中的中文提示词。

提取目标：
1. 镜头顺序与景别变化（远景/中景/近景/特写）
2. 运镜方式与节奏（推进、拉远、平移、跟拍、转场强弱）
3. 主体亮相逻辑（开场钩子、核心展示位、结尾收束）
4. 卖点推进路径（先展示什么、后强化什么、何时特写）
5. 人物/手部/道具互动模式
6. 场景氛围与情绪调性
7. 原始声音策略（环境声、口播/字幕节奏、BGM 情绪方向、声音与镜头配合方式）
8. 可迁移与不可迁移元素拆分

输出要求：
- 只提炼“表达方法”，不要继承参考商品品牌、文字、包装或不可迁移结构
- 若存在夸张特效或违规表达，需要明确写入“避让内容”
- 输出结果必须已经是可直接拼接到最终 prompt 的中文提示词段
- 不要输出 JSON，不要输出解释性文字，不要写字段名定义说明
```

### 3.1 中间能力正式输出要求

中间能力直接输出下面这段可拼装提示词，不再区分“示例格式”和“推荐模板”，统一按这套结构产出：

```text
参考视频已提炼的可迁移表达方法：
开场方式：{openingHook}
镜头节奏：{cameraRhythm}
卖点路径：{sellingPathJoined}
互动方式：{interactionPattern}
氛围调性：{sceneMood}
结尾方式：{endingStyle}
可迁移重点：{transferableElementsJoined}
避让内容：{nonTransferableElementsJoined}
```

要求：

+ 输出段落应尽量精炼，控制在 6~10 行内
+ 必须同时包含“可迁移重点”和“避让内容”
+ 这段输出结果直接作为 `referenceVideoMethodLines` 进入最终 prompt
+ 中间能力返回时就按上述结构输出完整中文提示词，不再额外包一层 JSON

### 3.2 可选扩展方案：结构化 JSON 输出

如果后续需要做结果回显、质量评估、字段级调试和多阶段复用，可升级为结构化 JSON 方案。当前不是主链路，只作为可选扩展保留。

#### 3.2.1 可选 Schema

```json
{
  "referenceVideoAnalysis": {
    "openingHook": "开场方式与前3秒钩子",
    "shotSequence": [
      "镜头1的主体亮相方式",
      "镜头2的景别或动作推进",
      "镜头3的细节或转化镜头"
    ],
    "cameraRhythm": "整体运镜方式与节奏，例如中快节奏、推近+特写交替",
    "sellingPath": [
      "先展示整体认知",
      "再推进细节卖点",
      "最后完成收束转化"
    ],
    "interactionPattern": "人物/手部/道具互动模式",
    "sceneMood": "场景氛围与情绪调性",
    "endingStyle": "结尾收束方式",
    "audioStrategyRaw": "参考视频识别出的原始声音策略，例如保留环境声、口播节奏偏快、BGM 偏轻快科技感",
    "transferableElements": [
      "可迁移的镜头语言或表达方式1",
      "可迁移的镜头语言或表达方式2"
    ],
    "nonTransferableElements": [
      "不可迁移的品牌、包装、字幕或侵权元素1",
      "不可迁移的强绑定元素2"
    ],
    "confidence": 0.0
  }
}
```

#### 3.2.2 字段释义

- `openingHook`
  - 参考视频开场如何抓住注意力，重点描述前 1~3 秒的主体亮相方式或视觉钩子。
- `shotSequence`
  - 按时间顺序拆解镜头主要内容，用于还原视频的推进顺序、景别变化和叙事节奏。
- `cameraRhythm`
  - 对整体运镜方式和节奏的概括，例如快慢节奏、推进为主、特写穿插、中景转特写等。
- `sellingPath`
  - 卖点推进路径，表示参考视频是按什么顺序建立认知、强化细节、完成转化的。
- `interactionPattern`
  - 人物、手部、道具与商品之间的互动模式，例如手持展示、上身试穿、桌面操作、开合演示。
- `sceneMood`
  - 场景氛围和情绪调性，例如科技感、生活方式感、高级感、轻快感、治愈感。
- `endingStyle`
  - 结尾的收束方式，例如主体定格、卖点特写收尾、氛围镜头回落、转化指向镜头。
- `audioStrategyRaw`
  - 参考视频识别出的原始声音策略，仅用于中间结果记录、调试、回放和后续裁剪，不建议原样直接进入最终 prompt。
- `transferableElements`
  - 可以迁移到新商品上的内容，通常是镜头语言、节奏组织、展示顺序、互动方式等“表达方法”。
- `nonTransferableElements`
  - 不可以直接迁移的内容，通常包括原商品品牌、包装字样、字幕文案、强绑定人物身份、侵权元素等。
- `confidence`
  - 本次中间识别结果的置信度。数值越高，说明该参考视频分析结果越稳定，越适合进入最终 prompt 的消费层。

说明：

+ 普通模式和高级模式仅代表使用的模型不一致，不再对应不同的提示词段

+ 视频电商场景下，不同品类对镜头结构、展示重点、风险约束和转化表达要求差异显著，建议补充品类级提示词配置

## 6.2 视频通用负向约束
说明：

+ 视频功能也需要类似图片生成的“通用负向约束”，但内容应针对视频生成风险，而不是直接复用图片版文案
+ 这一层约束在爆款复刻中作为所有品类和所有模式共享的基础负向约束
+ 建议拼装顺序为：主提示词 + 参考视频方法段 + 品类规则 + 通用负向约束 + 统一质量约束 + 参数行

## 8. 图片识别与扩展理解提示词
说明：

+ 该提示词用于在视频爆款复刻正式拼装 prompt 前，先基于用户上传的商品图做“品类 + 结构 + 场景 + 风险 + 卖点 + 风格”的扩展理解
+ 识别目标不是做投放埋点，而是补充会直接影响最终视频生成效果的关键信息
+ 输出品类必须命中 `videoReplicaCategoryOptions`，不允许输出自定义新品类

+ 在进入品类识别与扩展理解前，应先校验用户上传的 1~5 张图片是否属于同一商品

### 8.0 同一商品校验

用途：

+ 用于在正式执行 `video-replica` 前，先判断当前上传的 1~5 张图片是否属于同一商品
+ 若不是同一商品，则不进入后续品类识别和最终 prompt 拼装
+ 该校验优先级高于 `categoryLabel` 识别

推荐返回结构：

```json
{
  "sameProductCheck": {
    "isSameProduct": true,
    "confidence": 0.0,
    "reason": "一句简要判断依据",
    "mismatchSignals": ["信号1", "信号2"]
  }
}
```

判定原则：

+ 若多张图在主体结构、核心部件、材质形态、配色方案、品牌元素或商品类型上明显不一致，应判定为 `isSameProduct=false`
+ 若只是同一商品的不同角度、不同摆放方式、局部特写、轻微光照差异或不同背景，不应判定为不同商品
+ 若无法稳定判断，`isSameProduct` 应输出 `false`，并在 `reason` 中明确说明“无法确认属于同一商品”

失败处理要求：

+ 当 `isSameProduct=false` 时，后续不进入 `categoryLabel / productStructure / usageScene / displayRisks` 识别链路
+ 当 `isSameProduct=false` 时，后端应直接中止生成，并提示用户重新上传同一商品多视角图
+ 当 `isSameProduct=false` 时，不应仅靠回退 `通用品类` 继续正常生成

## 9. AI 润色提示词补充
说明：

+ `video-replica` 的 AI 润色不应只优化用户原始描述，还应同时吸收参考视频方法、品类约束和统一质量导向
+ 润色后的结果仍然服务于最终系统拼装，不替代系统主 prompt、`referenceVideoMethodLines` 与 `categorySpecificLines`
+ 若已识别出 `videoReplicaCategory`，润色时应显式要求文案更贴合该品类的镜头重点和风险边界

### 9.1 推荐润色提示词

```text
你是一位电商爆款复刻视频创意润色师。
请优化用户输入的视频创作描述，让表达更适合“先提炼参考视频爆款逻辑，再迁移到用户商品”的生成场景。

润色目标：
1. 保留用户原始意图，不改变商品本身，不发明用户没有表达的新卖点。
2. 让描述更聚焦镜头节奏、卖点推进、商品展示重点、场景氛围和转化表达。
3. 若已提供视频品类，请让润色结果更贴合该品类的展示重点与风险边界。
4. 若已提供创作模式，只将其视为模型选择信息，不需要写出普通/高级模式差异化提示词。
5. 输出结果必须适合继续参与最终 prompt 拼装，不要写成面向消费者的广告文案。

输入信息：
- 商品视频品类：{videoReplicaCategory}
- 创作模式：{modeLabel}
- 用户原始描述：{userDescription}

润色要求：
1. 优先把模糊表述改为可执行的镜头或卖点表达。
2. 不要引入品牌名、包装字样、虚假功效、夸张承诺或侵权元素。
3. 不要要求替换商品品类，不要要求改变商品真实结构、材质、颜色和比例。
4. 若用户描述过于宽泛，可适度补充“镜头重点、节奏感、氛围感、商品细节展示”这类可执行表达，但不能偏离用户原意。

只输出润色后的 1 段中文描述，不要输出解释。
```
