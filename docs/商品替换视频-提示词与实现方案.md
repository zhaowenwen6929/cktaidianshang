# 商品替换视频-提示词与实现方案

> 更新时间：2026-05-30
> 适用功能：`video-replace`（商品替换）

## 1. 需求目标

用户输入：

1. 上传 1 条待替换商品的视频（2~15s）
2. 上传 1~5 张同一商品的多视角图片
3. 选择创作模式（普通/高级）与参数（时长、比例、分辨率、音频）
4. 补充视频描述

系统输出：

- 将原视频中的原商品替换为用户上传的新商品
- 保留原视频的动作、运镜、节奏、场景关系和叙事结构
- 输出 1 条新的商品替换视频

## 2. 核心逻辑（优化后）

`video-replace` 的最终提示词必须由系统拼装，不直接使用用户原始输入。执行链路如下：

1. 原视频理解：提取镜头顺序、机位、动作、交互关系、场景结构和替换风险
2. 商品一致性约束：绑定用户上传商品图的真实结构、材质和多视角关系
3. 品类规则注入：根据商品所属标准电商品类补充展示重点和风险边界
4. 统一质量约束：直接使用最优效果所需的高标准成片约束
5. 用户补充融合：在硬约束不被破坏前提下吸收补充描述
6. 参数注入：模式标签、时长、比例、分辨率、音频写入最终 prompt

## 2.1 原视频中间分析 Prompt（中间能力）

建议作为商品替换视频的中间能力先执行一次。  
这一步不是提炼“爆款方法”，而是识别“原视频里哪些结构、动作、接触关系和镜头组织不能动”。

```text
你是一位商品替换视频镜头分析师。
请基于输入参考视频，识别后续“商品替换”任务必须保留的镜头结构、动作逻辑、接触关系和高风险镜头信息，并直接输出一段可拼装到最终生成提示词中的中文提示词。

分析目标：
1. 镜头顺序、景别变化和转场节奏。
2. 商品在各镜头中的出现方式，例如整体展示、局部特写、快速掠过、遮挡后恢复。
3. 人物、手部、道具、桌面、空间与商品之间的接触关系。
4. 商品动作或交互方式，例如手持、旋转、开合、按压、倒出、佩戴、上身、摆放。
5. 场景空间约束，例如桌面、居家、车载、人物身上、货架等。
6. 替换高风险点，例如高反光、透明材质、快速运动、近景特写、重遮挡、深色边缘、文字标签区域。
7. 仅当 `hasSound = 使用原视频声音` 时，继续分析原视频的声音策略，包括环境声、口播/字幕节奏、BGM 情绪方向以及声音与镜头动作的配合方式；若 `hasSound = 无声` 或 `智能匹配声音`，则不要求完整解析原视频声音内容。

输出要求：
1. 只提炼后续商品替换必须保留的结构与风险，不描述与替换无关的审美感受。
2. 输出必须是可直接拼接到最终 prompt 的中文提示词段，不要输出 JSON。
3. 不要写前言、结语或解释。
4. 若 `hasSound = 使用原视频声音`，可额外输出一条原始声音策略 `audioStrategyRaw`，供后续生成 `audioStrategyForPrompt`；若 `hasSound = 无声` 或 `智能匹配声音`，则不输出原始声音策略字段。
```

### 2.1.1 中间能力正式输出模板

```text
原视频已提炼的替换约束：
镜头结构：{shotStructure}
商品出现方式：{productPresence}
动作与交互：{interactionFlow}
场景约束：{sceneConstraint}
替换高风险点：{replacementRisks}
声音策略：{audioStrategyRaw}
必须保留：{mustKeepJoined}
禁止破坏：{mustAvoidJoined}
```

说明：

- 这段输出结果建议命名为 `videoReplaceMethodLines`
- 它是商品替换视频最终 prompt 中的原视频约束段
- 它不同于爆款复刻的 `referenceVideoMethodLines`，这里强调的是“不能动什么”，不是“学习怎么卖”
- 其中 `声音策略：{audioStrategyRaw}` 仅在 `hasSound = 使用原视频声音` 时输出；若 `hasSound = 无声` 或 `智能匹配声音`，该行不输出

### 2.1.2 是否解析原视频声音

说明：

- 商品替换视频的中间分析主目标仍然是画面结构、动作、接触关系、遮挡恢复和高风险镜头
- 原视频声音不是第一优先级，但建议按 `hasSound` 条件解析
- 建议区分：
  - 画面中间分析：默认执行
  - 声音中间分析：按音频选项条件执行

推荐规则：

```json
{
  "videoReplaceAudioAnalysisRules": {
    "hasSound=使用原视频声音": {
      "needAudioAnalysis": true,
      "usage": "建议解析原视频声音，输出 audioStrategyRaw，用于后续生成 audioStrategyForPrompt。"
    },
    "hasSound=无声": {
      "needAudioAnalysis": false,
      "usage": "不需要完整解析原视频声音内容；最多只保留画面节奏层面的参考，不生成实际声音内容。"
    },
    "hasSound=智能匹配声音": {
      "needAudioAnalysis": false,
      "usage": "不需要完整解析原视频声音内容；可仅参考原视频节奏组织，不复用具体声音方案。"
    }
  }
}
```

结论：

- `使用原视频声音`
  - 建议解析原视频声音
  - 输出 `audioStrategyRaw`
- `无声`
  - 不建议完整解析原视频声音
  - 只保留视觉节奏参考即可
- `智能匹配声音`
  - 不建议完整解析原视频声音
  - 只保留节奏组织参考即可

## 3. 最终执行 Prompt（直接用于 video-replace）

```text
你是一位商品替换视频生成导演与电商商品一致性审核专家。
请基于用户上传的 1 条参考视频《{videoName}》和 {sourceImageCount} 张同一商品的多视角参考图，执行“商品替换”任务。
目标：将原视频中的原商品替换为用户上传的新商品，并生成一条新的电商视频。

{videoReplaceMethodLines}

镜头与动作要求：
1. 严格保留参考视频中的镜头顺序、机位关系、运镜节奏、主体动作、交互逻辑、场景空间关系与叙事结构，不得擅自改写脚本。
2. 原视频中的情绪节奏、切镜逻辑、景别关系和镜头时长应尽量保持一致，只替换商品本体和与商品强相关的局部信息。
3. 若原视频中已识别出高风险替换镜头、强遮挡恢复、快速运动特写、透明材质区域或文字标签区域，需优先按 `videoReplaceMethodLines` 中的约束执行，不得因替换导致原视频结构失真。

商品一致性要求：
1. 新商品必须以用户上传的多视角图片为唯一商品依据，保持同一商品在颜色、材质、结构、纹理、比例、品牌元素与细节上的一致性。
2. 如果参考图包含正面、侧面、背面、俯视、局部特写等信息，需在不同镜头中正确调用对应视角，避免视角跳变、结构错乱、细节丢失。
3. 替换后商品尺寸、透视、受力、遮挡、高光、反射、阴影和接触关系必须与原场景真实匹配。
4. 不得替换为其他品类，不得凭空增删商品组件，不得改变商品核心卖点和真实外观。
5. 若已识别 `productStructure`，需优先将其作为结构保护重点写入本段，例如按钮、接口、边框、开孔、表盘、拉链、泵头、提手等关键结构不得被改坏。
6. 若已识别 `usageScene`，需优先将其作为接触关系和尺度逻辑约束写入本段，例如手持、上身、桌面、家居空间、车载等场景中的透视、受力、遮挡和展示方式需与原视频一致且自然可信。

{categorySpecificLines}

{videoUniversalNegativeLines}

视频质量要求：
1. 输出应保持商业级真实感，避免闪烁、抖动、漂移、穿帮、边缘融化、贴图错位、结构重影和帧间不一致。
2. 人手持握、人物穿戴、桌面摆放、液体接触、开合按压等交互场景，需要保证商品与人物/环境接触自然。
3. 若参考视频存在文字、Logo、包装、标签或屏幕内容，替换时需尽量与新商品信息协调，避免明显冲突。
4. 更严格约束跨镜头商品一致性，尤其是近景、特写、转场和遮挡恢复后的细节连续性。
5. 更严格控制商品边缘融合、透明材质、金属反光、高光过渡、阴影衔接和环境反射的真实性。
6. 更严格控制人与商品、商品与道具、商品与台面的接触可信度，避免悬浮感、穿插错误和受力异常。
7. 更严格抑制帧间闪烁、结构漂移、局部变形、贴图跳动和颜色忽明忽暗。
8. 在保证原视频节奏不变的前提下，让最终成片达到更强的商业广告质感与可投放质量。
9. 若已识别 `displayRisks`，需优先将其作为高风险项写入本段，例如高反光、透明材质、深色边缘、圆形边界、文字完整性等都需被重点保护。
10. 若已识别 `styleDirection` / `priceTone`，仅作为弱约束补充到本段，用于控制成片的氛围调性、商业观感和价格带气质，不得压过商品真实一致性。

{soundSpecificLines}

生成模式：{modeLabel}；视频时长：{duration}；目标比例：{ratio}；目标分辨率：{resolution}；音频要求：{hasSound}。
用户补充创作要求：{userDescription}
若已识别 `sellingPointType`、`targetAudience`、`audienceNeed`，可仅作为弱约束在理解用户补充时吸收，用于调整卖点排序、表达角度和氛围偏好；不得改写商品结构、品类和原视频动作节奏。
弱约束写法示例：
- 不建议直接写成“目标人群：xxx”“核心需求：xxx”这类生硬字段串。
- 更推荐写成自然执行语义，例如：若商品更偏结构功能型卖点，且更适合数码消费人群，核心需求偏向便携与专业感，则可在不改变商品真实结构和原视频动作节奏的前提下，适度强化关键结构细节、操作场景可信度和克制专业的表达方式。

在不破坏“动作和运镜不变、商品真实一致”的前提下，优先满足用户补充要求。
最终只输出一条完成商品替换的新视频。
```

## 4. 创作模式使用说明

说明：

+ 普通模式和高级模式仅代表使用的模型不一致，不再对应不同的提示词段
+ 最终执行 prompt 统一直接使用更优效果所需的高标准质量约束
+ `modeLabel` 仍保留在参数行中，便于任务记录、排查和模型路由

## 6. 最终提示词拼装补充
说明：

+ 商品替换视频最终提示词建议按“通用主提示词 + 品类规则 + 通用负向约束 + 统一高标准质量约束 + 视频声音规则 + 参数行 + 用户补充”拼装
+ 建议新增 `{categorySpecificLines}`，用于注入品类级结构保护、接触风险和展示重点
+ 建议新增 `{videoUniversalNegativeLines}`，用于注入视频通用负向约束
+ 建议将“视频声音”做成前台 3 个选项，并像图片功能一样提供“选项值 -> 提示词”的结构化映射
+ 若后续补充原视频声音理解，建议区分 `audioStrategyRaw` 与 `audioStrategyForPrompt`：前者仅用于记录原视频声音表达，后者才是最终 prompt 中唯一生效的声音策略

## 8. AI 润色提示词补充
说明：

+ `video-replace` 的 AI 润色不应只优化用户原始描述，还应同时吸收品类约束和统一质量导向
+ 润色后的结果仍然服务于最终系统拼装，不替代系统主 prompt 与 `categorySpecificLines`
+ 若已识别出 `videoReplaceCategory`，润色时应显式要求文案更贴合该品类的接触风险和结构重点

### 8.1 推荐润色提示词

```text

1. 保留用户原始意图，不改变商品本身，不发明用户没有表达的新卖点。

- 创作模式：{modeLabel}
```

## 9. 后端实现建议

建议服务端按三阶段执行：

1. `视频理解`
   - 提取镜头切分、主体运动轨迹、机位、镜头时长、交互对象、场景语义
2. `商品一致性建模`
   - 基于 1~5 张商品图构建统一商品表征，覆盖颜色、材质、结构、纹理、局部细节、多视角关系
3. `逐镜头替换生成`
   - 对每个镜头执行商品替换与时序一致性约束，最后输出整段视频

建议增加的服务端校验：

1. 校验商品图是否属于同一商品
2. 校验视频时长是否在 2~15s
3. 校验商品图数量是否在 1~5 张
4. 校验是否存在无法替换的高风险镜头
5. 对成片进行闪烁、结构漂移、边缘穿帮的自动质检

## 10. 验收标准

满足以下标准可判定为可上线版本：

1. 原视频动作和运镜基本不变
2. 替换后的商品在全片中为同一商品，不出现形变和视角错乱
3. 人手接触、桌面摆放、遮挡关系自然
4. 高光、阴影、透视与场景一致
5. 无明显闪烁、漂移、重影、边缘融化
6. 用户输入的重点要求能在成片中被体现
7. 品类相关的结构重点和风险边界未被破坏
