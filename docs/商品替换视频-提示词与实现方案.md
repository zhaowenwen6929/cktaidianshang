# 商品替换视频-提示词与实现方案

## 1. 需求目标

用户上传：

1. 1条原始参考视频
2. 1~5张同一商品的多视角图片
3. 选择创作模式
4. 补充视频描述

系统输出：

- 将原视频中的原商品替换为用户上传的新商品
- 保留原视频的动作、运镜、节奏、场景关系
- 生成1条新的商品替换视频

适用功能：

- `video-replace` 商品替换

## 2. 前端交互方案

页面字段建议：

1. `上传原视频`
2. `上传替换商品图`
3. `创作模式`
4. `视频时长`
5. `视频比例`
6. `视频分辨率`
7. `视频描述`

交互文案建议：

- 原视频上传提示：`请上传1个待替换商品的视频，时长2~15s，小于50M，支持MP4/MOV`
- 商品图上传提示：`最多5张，请上传同一商品的多视角图片，用于替换视频中的原商品`
- 视频描述占位：`请描述替换后的商品视频要求，例如：保留原视频动作和运镜不变，使用上传的多视角商品图替换原商品，重点确保结构一致、透视自然、手持接触真实。`

## 3. 生成入参建议

建议前端提交以下结构给后端或模型层：

```json
{
  "toolKey": "video-replace",
  "modeId": "normal",
  "modeLabel": "普通模式",
  "ratio": "竖9:16",
  "resolution": "480p",
  "duration": "10s",
  "hasSound": "保留原视频音频",
  "sourceImages": [
    "1~5张同一商品多视角图"
  ],
  "sourceVideo": [
    "1条待替换商品的视频"
  ],
  "userDescription": "用户输入的视频描述",
  "finalPrompt": "拼装后的最终执行提示词"
}
```

其中：

- `userDescription`：保留用户原始描述，便于任务回显和客服排查
- `finalPrompt`：真正给模型执行的结构化提示词

## 4. 主提示词

以下提示词可直接用于 `video-replace` 能力：

```text
你是一位商品替换视频生成导演与电商商品一致性审核专家。
请基于用户上传的 1 条参考视频《{videoName}》和 {sourceImageCount} 张同一商品的多视角参考图，执行“商品替换”任务。
目标：将原视频中的原商品替换为用户上传的新商品，并生成一条新的电商视频。

镜头与动作要求：严格保留参考视频中的镜头顺序、机位关系、运镜节奏、主体动作、交互逻辑、场景空间关系与叙事结构，不得擅自改写脚本。

商品一致性要求：
1. 新商品必须以用户上传的多视角图片为唯一商品依据，保持同一商品在颜色、材质、结构、纹理、比例、品牌元素与细节上的一致性。
2. 如果参考图包含正面、侧面、背面、俯视、局部特写等信息，需在不同镜头中正确调用对应视角，避免视角跳变、结构错乱、细节丢失。
3. 替换后商品尺寸、透视、受力、遮挡、高光、反射、阴影和接触关系必须与原场景真实匹配。
4. 不得替换为其他品类，不得凭空增删商品组件，不得改变商品核心卖点和真实外观。

视频质量要求：
1. 输出应保持商业级真实感，避免闪烁、抖动、漂移、穿帮、边缘融化、贴图错位、结构重影和帧间不一致。
2. 人手持握、人物穿戴、桌面摆放、液体接触、开合按压等交互场景，需要保证商品与人物/环境接触自然。
3. 若参考视频存在文字、Logo、包装、标签或屏幕内容，替换时需尽量与新商品信息协调，避免明显冲突。

生成模式：{modeLabel}；视频时长：{duration}；目标比例：{ratio}；目标分辨率：{resolution}；音频要求：{hasSound}。
用户补充创作要求：{userDescription}

在不破坏“动作和运镜不变、商品真实一致”的前提下，优先满足用户补充要求。
最终只输出一条完成商品替换的新视频。
```

## 5. 模式建议

### 5.1 普通模式

定位：

- 满足基础商品替换
- 优先保证镜头延续与主体替换成功

建议文案：

- `使用商品替换普通模型，基于参考视频与 1~5 张商品多视角图完成原商品替换，保留动作和运镜。`

已写入最终执行提示词的附加约束：

```text
普通模式执行重点：
1. 优先保证商品替换成功，动作不变、运镜不变、主体不跑偏。
2. 优先保证主要镜头中的商品结构、颜色和大轮廓稳定一致。
3. 在保证生成稳定的前提下，尽量还原原视频中的场景接触关系与真实观感。
```

### 5.2 高级模式

定位：

- 强化多镜头一致性
- 强化边缘融合、光影透视、接触真实感
- 更适合手持、穿戴、近景特写等复杂镜头

建议文案：

- `使用商品替换高级模型，强化多镜头商品一致性、边缘融合、光影透视与商业成片稳定性。`

已写入最终执行提示词的附加约束：

```text
高级模式附加要求：
1. 强化跨镜头商品一致性，尤其是近景、特写、转场和遮挡恢复后的细节连续性。
2. 强化商品边缘融合、透明材质、金属反光、高光过渡、阴影衔接和环境反射的真实性。
3. 强化人与商品、商品与道具、商品与台面的接触可信度，避免悬浮感、穿插错误和受力异常。
4. 强化整片稳定性，重点抑制帧间闪烁、结构漂移、局部变形、贴图跳动和颜色忽明忽暗。
5. 在保证原视频节奏不变的前提下，让最终成片达到更强的商业广告质感与可投放质量。
```

## 6. 提示词拼装策略

前端不要直接把用户输入当最终 prompt 发给模型，而是建议按以下顺序拼装：

1. 系统角色
2. 任务目标
3. 原视频保留约束
4. 商品一致性约束
5. 成片质量约束
6. 模式参数
7. 用户补充描述

建议：

- 用户输入为空时，也要输出默认约束版本
- 用户输入存在时，仅作为补充要求，不可覆盖“动作和运镜不变”“商品真实一致”这两个硬约束

## 7. 后端实现建议

建议服务端按三阶段执行：

1. `视频理解`
   - 提取镜头切分、主体运动轨迹、机位、镜头时长、交互对象、场景语义
2. `商品一致性建模`
   - 基于 1~5 张商品图构建统一商品表征，覆盖颜色、材质、结构、纹理、局部细节、多视角关系
3. `逐镜头替换生成`
   - 对每个镜头执行商品替换与时序一致性约束，最后输出整段视频

建议增加的服务端校验：

1. 校验商品图是否属于同一商品
2. 校验视频时长是否在 2~15s
3. 校验商品图数量是否在 1~5 张
4. 校验是否存在无法替换的高风险镜头
5. 对成片进行闪烁、结构漂移、边缘穿帮的自动质检

## 8. 验收标准

满足以下标准可判定为可上线版本：

1. 原视频动作和运镜基本不变
2. 替换后的商品在全片中为同一商品，不出现形变和视角错乱
3. 人手接触、桌面摆放、遮挡关系自然
4. 高光、阴影、透视与场景一致
5. 无明显闪烁、漂移、重影、边缘融化
6. 用户输入的重点要求能在成片中被体现
