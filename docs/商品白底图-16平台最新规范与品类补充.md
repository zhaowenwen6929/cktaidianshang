# 商品白底图 16 平台最新规范与品类补充

> 更新时间：2026-04-30
>
> 说明：本文件基于 2026-04-30 可公开检索到的官方或一手来源整理。由于不少平台的图片审核规则只在商家后台、卖家中心、开放平台或类目后台中展示，公开网页并不总能检索到完整版本，因此本文将规则分为三类：
>
> - A 类：官方明确公开
> - B 类：官方公开但为间接说明 / 接口说明 / 卖家学院内容
> - C 类：公开网页可见但非官方，需要商家后台二次核验

## 1. 结论先行

如果你要做一个“统一覆盖 16 平台、全品类”的商品白底图功能，系统默认规则不应该按“最宽松平台”设计，而应该按“可跨平台复用的最严格交集”设计。

推荐统一基线如下：

```text
主图/白底图默认使用纯白背景（RGB 255,255,255）；仅保留实际售卖商品主体；不加人物、手模、道具、文字、水印、Logo、边框、贴纸、价格标签、促销角标和其他营销元素；商品主体完整、居中、清晰、不变形；允许极弱接触阴影，但默认不做明显投影；保留真实材质、颜色、纹理、透明件与金属高光；不得使用与实物不符的渲染替代图。
```

原因很简单：

- Amazon 和 TikTok Shop 已公开明确要求首图纯白背景
- 小红书开放平台对商品图尺寸、比例有明确要求
- Ozon 官方卖家内容明确主图建议白色或浅色中性背景
- 其他多个平台公开网页规则分散或不完整，但白底、无字、主体清晰、无牛皮癣，依然是跨平台最稳妥的统一做法

## 3. 平台逐条补充

### 3.1 亚马逊 Amazon

级别：A 类，官方明确公开

公开可核验规则：

- MAIN image 必须是白底
- 背景应为纯白 `RGB 255,255,255`
- 仅展示售卖商品本体
- 不允许文字、Logo、水印、边框、图形覆盖
- 商品应占画面大部分，公开内容里多次提到约 `85%`
- 不能用占位图、插画、非实物渲染替代

系统建议：

- 作为全平台统一基线的最高优先级来源之一
- 对 Amazon 选项强制关闭营销文字、明显投影、复杂道具

来源：

- Amazon Seller Forums / Product image requirements（检索时间 2026-04-30）
- https://sellercentral.amazon.com/seller-forums/discussions/t/5eef969a1508af21fb64e9db01ba5a7e?mons_sel_locale=zh_CN
- https://sellercentral.amazon.com/seller-forums/discussions/t/ab884127-f9b4-4053-8096-4991e1d60d1f

### 3.2 TikTok Shop

级别：A 类，官方明确公开

公开可核验规则：

- 主图必须是纯白背景
- 主图必须展示商品正面实体视图
- 不得添加 Logo、文字、边框、水印、图形
- 图片最小尺寸 `600 x 600`
- 图片必须真实准确反映售卖商品
- 不允许数字渲染占位图

系统建议：

- 与 Amazon 同级，纳入“强约束平台”
- TikTok Shop 平台选项应强制输出纯白首图

来源：

- TikTok Shop Product Listing Policy（检索时间 2026-04-30）
- https://seller-us.tiktok.com/university/essay?default_language=en&identity=1&knowledge_id=3196690250417921

### 3.3 小红书电商

级别：B 类，官方公开但偏接口/开放平台说明

公开可核验规则：

- 商品图片尺寸支持 `800x800`、`750x1000`
- 商品图比例支持 `1:1`、`3:4`
- 格式支持 `JPG/PNG/JPEG`
- 商品详情图宽度 `750px~1242px`

公开文档没有在当前检索结果里明确写“白底强制”，但其商品图结构与展示位天然支持标准白底图。

系统建议：

- 如果用户选择小红书电商，白底图仍建议走纯白基线
- 同时允许服饰、美妆、穿戴类保留 `3:4` 比例兼容能力

来源：

- 小红书开放平台 Create SPL ITEM / Create SPL（检索时间 2026-04-30）
- https://school.xiaohongshu.com/en/open/product/create-spl-item.html
- https://school.xiaohongshu.com/en/open/product/create-spl.html

### 3.4 OZON

级别：B 类，官方卖家内容

公开可核验规则：

- 官方卖家内容明确主图通常使用白色或浅色中性背景
- 商品应完整可见
- 居中展示更优

系统建议：

- Ozon 允许“白或浅色中性底”的公开表达
- 但为了 16 平台统一复用，系统主策略仍用纯白

来源：

- Ozon Seller Media（检索时间 2026-04-30）
- https://seller.ozon.ru/media/interviews/kak-samomu-sdelat-foto-dlya-marketplejsov/

### 3.5 阿里国际站 Alibaba.com

级别：B 类，官方卖家学院

公开可核验信息：

- 官方卖家学院明确要求重视商品图片质量
- 强调商品图片是买家看到的第一信息
- 公开检索结果中未看到统一“主图必须纯白”的强制条款

系统建议：

- 对阿里国际站默认启用白底标准图
- 但后续如果接入商家后台数据，可再按类目扩展为“白底/棚拍/工业图”等模式

来源：

- Alibaba Seller Central Learning Center（检索时间 2026-04-30）
- https://seller.alibaba.com/learningcenter/content/detail/PXJTD6WM.htm

### 3.6 Shopee

级别：C 类，公开官方页难检索到；公开接入文档可见

公开可见但非 Shopee 官方直接文档的信息：

- 常见接入文档要求主图清晰
- 仅展示售卖商品
- 避免文字和图形
- 商品占比约 `70%`
- 常见尺寸建议 `1024 x 1024`

系统建议：

- Shopee 默认也用纯白主图，避免多市场差异
- 如后续区分 ShopeeMall 与普通店，可再拆成“严格白底”和“浅色轻场景”两档

参考来源：

- ChannelEngine marketplace guide（检索时间 2026-04-30）
- https://support.channelengine.com/hc/en-us/articles/4409503364509-Shopee-marketplace-guide

### 3.7 SHEIN

级别：C 类，公开接入文档可见，非 SHEIN 卖家中心原始规则页

公开可见信息：

- 图片比例可为 `1:1`、`3:4`、`4:5`、`13:16`
- 方图示例分辨率 `900x900` 或 `2200x2200`
- 格式支持 `JPG/JPEG/PNG`

系统建议：

- 白底功能默认仍输出纯白
- 对服饰类允许系统生成 `3:4`

参考来源：

- ChannelEngine marketplace guide（检索时间 2026-04-30）
- https://support.channelengine.com/hc/en-us/articles/21552893542941-SHEIN-marketplace-guide

### 3.8 淘宝 / 天猫 / 京东 / 拼多多 / 1688 / 抖音电商 / 快手电商 / Temu / 速卖通

级别：C 类

在 2026-04-30 的公开检索结果中，我没有拿到足够清晰、可直接引用的统一官方规则页来支撑“逐条硬规范”落表。能检索到的大多是：

- 卖家服务商文章
- 教程型博客
- 第三方工具站整理
- 平台生态从业者经验总结

这类信息能反映实操趋势，但不适合直接当做“唯一官方标准”写进产品逻辑。

因此这几个平台当前建议处理方式是：

- 系统产品层按“统一严格白底基线”执行
- 商务 / 运营 / 类目负责人后续在商家后台补齐类目审核截图
- 再把后台规则回填为结构化配置

### 4.2 平台优先级

建议平台规则优先级：

1. 明确官方硬规则优先
2. 若平台公开规则不完整，则回退到统一严格白底基线
3. 若类目存在更严格子规则，则类目规则覆盖平台默认规则

## 5. 品类补充规则

下面这部分不是“16 平台逐平台官方规则”，而是为了让你的功能真正可落地而补上的“系统品类规则层”。它的作用是：当 AI 识别出品类后，再对最终提示词追加更准确的约束。

### 5.1 服饰类

适用品类：

- 女装
- 男装
- 童装
- 内衣
- 袜子

建议规则：

- 默认平铺或挂拍，不带真人模特
- 去除衣架、夹子、背景布褶皱
- 保留版型、面料纹理、褶皱结构
- 不改颜色，不改领型，不改袖长
- 对白色服饰增加轮廓边缘保护

提示词补充：

```text
该商品属于服饰类，请保持服装真实版型、面料纹理、垂感与轮廓结构，不添加真人模特、衣架、夹子与摆拍道具，避免把服饰边缘抠坏或压扁。
```

### 5.2 鞋靴类

适用品类：

- 运动鞋
- 皮鞋
- 凉鞋
- 靴子

建议规则：

- 保留鞋面材质、鞋底结构、鞋带与开口形态
- 一双鞋默认保持整齐成对展示
- 禁止错位、镜像错误、鞋底异常变形

提示词补充：

```text
该商品属于鞋靴类，请保留鞋面材质、鞋底结构、鞋带与鞋型轮廓，保证左右脚或成对展示逻辑正确，不出现镜像错误、鞋底变形或鞋口塌陷。
```

### 5.3 箱包类

适用品类：

- 双肩包
- 女包
- 行李箱
- 钱包

建议规则：

- 保持包体立体结构
- 保留五金、拉链、肩带、手柄细节
- 不压扁、不塌陷

### 5.4 珠宝饰品类

适用品类：

- 项链
- 戒指
- 耳饰
- 手链

建议规则：

- 强化边缘净度和高反光控制
- 保留金属、钻石、珍珠、宝石高光
- 默认弱接触阴影，不加重阴影
- 防止透明件、细链条丢失

### 5.5 美妆个护类

适用品类：

- 护肤品
- 彩妆
- 洗护
- 香水

建议规则：

- 包装文案和品牌标识必须保真
- 防止瓶身变形、泵头缺失、喷嘴错位
- 透明瓶和高反光包装重点保护边缘

### 5.6 食品饮料类

适用品类：

- 零食
- 茶饮
- 粮油
- 保健食品

建议规则：

- 仅展示合法可售商品包装
- 不伪造食材外露效果
- 不自动增加蒸汽、液体飞溅、配菜摆盘
- 保留包装净含量、口味、规格信息清晰可辨

### 5.7 家居百货类

适用品类：

- 收纳用品
- 厨具
- 清洁用品
- 家纺

建议规则：

- 保持结构比例准确
- 套装商品必须保证配件完整
- 对玻璃、塑料、金属混合材质重点保真

### 5.8 家电数码类

适用品类：

- 小家电
- 耳机
- 手机配件
- 鼠标键盘

建议规则：

- 保留接口、按键、屏幕、线材等关键结构
- 不得虚构发光效果
- 金属和塑料材质边界清晰
- 对黑色数码产品防止边缘糊边

### 5.9 家具大件类

适用品类：

- 桌椅
- 柜体
- 沙发

建议规则：

- 允许更大留白，但主体必须完整
- 强化体积感和边角直线
- 不得压缩透视导致家具比例失真

### 5.10 母婴玩具类

适用品类：

- 婴童用品
- 益智玩具
- 毛绒玩具

建议规则：

- 禁止加入儿童模特
- 保留软材质、绒面、塑胶件真实质感
- 对多配件商品保持组件齐全

### 5.11 宠物用品类

适用品类：

- 宠物窝
- 宠物玩具
- 喂食器

建议规则：

- 默认不加入宠物模特
- 只展示售卖商品本体
- 对软垫、绳结、塑料件分别保真

### 5.12 汽配五金类

适用品类：

- 车载支架
- 工具
- 配件耗材

建议规则：

- 强调结构、尺寸、孔位、棱边准确
- 金属件保持真实反光
- 禁止虚构安装环境

## 6. 适合写进系统的“平台 + 品类”组合逻辑

```ts
type RuleLevel = "platform" | "category" | "global";

type GoodsWhiteRuleConfig = {
  id: string;
  level: RuleLevel;
  target: string;
  prompt: string;
  priority: number;
};
```

建议组合顺序：

```text
全局白底规则
+ 平台规则
+ 品类补充规则
= 最终生成提示词
```

优先级建议：

- `platform` 优先级 200
- `category` 优先级 300
- `global` 优先级 100

也就是：

- 先有统一白底基线
- 再叠平台规则
- 再叠品类结构保护规则

## 7. 最终落地建议

### 7.1 产品层

- 平台选择器里保留 16 平台
- 增加“规则来源级别”字段，便于运营知道哪些是官方硬规则，哪些是系统策略

### 7.2 算法层

- 商品图上传后先跑品类识别
- 再拼平台规则
- 再拼品类补充规则
- 最终交给白底图模型生成

### 7.3 运营层

- 对 C 类平台，继续从商家后台补截图和原始规则
- 类目负责人可按一级类目维护额外禁用项

## 8. 当前最可靠的统一提示词建议

```text
请基于上传的商品原图，生成适用于电商平台上架的合规商品白底主图。输出纯白背景（RGB 255,255,255），仅保留实际售卖商品主体，不添加人物、手模、道具、文字、水印、Logo、边框、贴纸、价格标签、营销角标或任何其他促销元素；商品主体完整居中，边缘清晰锐利，不截断、不缺角、不拉伸、不变形；默认仅允许非常轻微且自然的接触阴影，禁止明显投影；保留商品真实颜色、材质、纹理、透明件、金属件与高反光细节，不过曝，不过暗，不过度磨皮，不过度锐化，不得使用与实物不符的渲染替代图；请同时遵守目标平台的主图展示要求，并保留该商品所属品类应有的结构特征与外观细节，最终输出为真实、专业、干净、可直接上架的标准商品白底图。
```
