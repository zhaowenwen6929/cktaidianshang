## 端到端使用流程
1. 用户上传商品图。
2. 用户选择提取模式：`专项提取 / 全能提取`。
3. 系统根据当前模式动态切换可选的 `产品场景` 和 `出图比例` 列表，并自动校验当前已选值是否合法。
4. 用户选择 `产品场景 / 出图比例 / 透明底图`。
5. 系统按 `模式规则 + 设置值扩展 + 通用硬约束` 组装最终提示词并提交。
6. 输出可直接用于 POD 后续链路的印花提取结果；若开启透明底图，则优先输出便于后续贴图和排版的透明背景结果。

## 4. 场景识别与比例回填规则（内部增强链路）
说明：

+ 当前页面没有显式图片识别入口，但印花图提取天然适合在上传后做内部识别，用于自动回填 `podExtractScene`
+ 比例推荐不应由模型自由生成，而应由“识别到的场景 + 当前模式允许比例”联合决定

### 4.1 场景识别提示词
```json
你是POD印花图提取场景识别助手。请根据上传图片识别最合适的产品场景，并给出可用于规则回填的结构化结果。

仅允许从以下场景中选择：通用、手机壳、家纺、桌布、全能、全幅印、凤玲、挂钟。

要求：
1) 只关注真实售卖商品上的图案区域，不要把背景道具当作主体。
2) 若商品弧面明显且有开孔，优先手机壳。
3) 若布料褶皱、织纹干扰明显，优先家纺或桌布。
4) 若图案为大面积铺满，优先全幅印。
5) 若圆形盘面或钟面结构明显，优先挂钟。
6) 遮挡重、形变大、难以单一归类时，优先全能。
7) 不确定时返回通用。
8) 只输出 JSON，不要输出解释。

输出格式：
{
  "podExtractScene": "通用|手机壳|家纺|桌布|全能|全幅印|凤玲|挂钟",
  "confidence": 0.0,
  "evidence": ["证据1", "证据2"],
  "needsUserConfirm": false
}
```

### 4.2 场景回填规则
+ `confidence < 0.70` 时，回填 `podExtractScene=通用`，并标记 `needsUserConfirm=true`
+ 多场景同时命中时优先级：`手机壳 > 挂钟 > 全幅印 > 家纺 > 桌布 > 凤玲 > 全能 > 通用`
+ 遮挡重、形变重时允许直接回填 `全能`

## 拼装规则
### 拼装顺序
1. `taskGoal`（任务目标）
2. `modeRulePrompt`（模式规则正文）
3. `parameterLine`（参数行）
4. `optionValuePrompts`（设置值扩展约束）
5. `requiredRule`（必须满足）
6. `forbiddenRule`（禁止事项）
7. `universalNegative`（通用负向约束）
8. `universalQuality`（通用质量要求）
9. `supplement`（补充说明，可选，当前页面无该字段）

组装要求：

+ `requiredRule / forbiddenRule / universalNegative / universalQuality` 属于不可裁剪段
+ token 超限时，仅允许按 `supplement -> optionValuePrompts -> modeRulePrompt` 顺序裁剪
+ 当前页面无 `supplement` 时整段删除，不保留占位
+ `podExtractTransparentBackground=1` 时，对应的 `valuePrompt` 不可被省略

## 三个关键能力的提示词配置
### 图片识别获取信息
当前功能没有显式图片识别入口，但该功能适合接“场景识别 + 比例回填”的内部识别链路。

若接入识别，当前最应该识别的是：

+ `podExtractScene`
+ `podExtractRatio`（按场景和模式允许值联合回填，不建议模型自由输出）

不建议当前识别：

+ `podExtractMode`

原因：

+ `podExtractMode` 更像用户主动选择的提取难度档位，而不是纯视觉识别字段
+ `专项提取 / 全能提取` 取决于业务预期和容错策略，不应完全交给模型代选

### AI帮写
当前功能没有显式 `AI assist` 入口，可不接该模块。

### 文本润色
当前功能没有显式 `supplement` 输入框，可不接该模块。

## 结论
POD 印花 > 印花图提取当前是一个“轻表单、强规则、强链路适配”的功能：

1. 当前真实字段为 `podExtractMode / podExtractScene / podExtractRatio / podExtractTransparentBackground`。
2. 当前最核心的开发落点是把模式规则、设置值扩展、通用硬约束稳定组装成 prompt。
3. `产品场景` 与 `出图比例` 不是孤立字段，而是受模式切换联动约束。
4. `透明底图` 虽然是开关字段，但对最终结果形态影响很大，必须单独进入拼装。
5. 当前没有平台字段、没有补充说明、没有显式 AI 帮写入口，不要把非必要模块提前混入主链路。
