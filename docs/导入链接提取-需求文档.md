# 导入链接提取-需求文档

## 1. 文档信息

| 项 | 内容 |
| --- | --- |
| 功能名称 | 导入链接提取 |
| 所属产品 | AI电商 |
| 关联一级分组 | 电商套图、视频创作 |
| 关联工具 | `set-replica`（爆款套图复刻）、`video-replica`（爆款复刻） |
| 页面类型判定 | AI功能与提示词类 / 上传导入类 |
| 类型判定置信度 | 高 |
| 输出目标 | 在参考图/参考视频上传区新增“导入链接提取”能力，并补齐校验、授权、提取结果标记、异常提示与信息追溯能力 |

---

## 2. 需求背景

当前 `爆款套图复刻` 与 `视频创作 > 爆款复刻` 都依赖用户先准备本地参考素材，再上传到参考图或参考视频区域。  
为了降低素材准备门槛，需要支持用户直接粘贴 TikTok、抖音、小红书内容链接，由系统完成内容提取，并自动回填到对应上传区。

该能力需要同时满足以下目标：

1. 用户可直接从外部内容平台导入参考素材。
2. 用户必须确认已获得内容使用授权。
3. 链接输入必须先做有效性校验，再允许进入授权与提取流程。
4. 提取成功后的素材需要保留来源信息，便于后续核查。
5. 提取失败时需要在导入区内原位提示错误，且不清空用户输入内容。
6. 提取来源信息悬浮信息框必须尽量完整显示，不能被局部上传区域裁剪。

---

## 3. 适用范围

### 3.1 本期纳入范围

1. `set-replica` 的 `参考图` 上传区。
2. `video-replica` 的 `参考视频` 上传区。
3. 导入入口 UI、授权勾选、链接校验、提取成功回填、提取失败提示、来源信息展示。

### 3.2 本期不纳入范围

1. 真实后端抓链解析服务设计。
2. 登录态平台鉴权。
3. 外部平台反爬、限流与版权风控中台设计。
4. 批量粘贴多条链接。
5. 除 TikTok / 抖音 / 小红书外的平台支持。

---

## 4. 用户与使用场景

### 4.1 目标用户

1. 需要快速复刻爆款内容风格的电商运营。
2. 缺少本地素材整理时间，希望直接引用平台内容的设计/内容人员。

### 4.2 核心场景

1. 用户在 `爆款套图复刻` 中粘贴小红书或抖音图片/视频内容链接，系统提取图片关键帧并自动填入 `参考图`。
2. 用户在 `视频创作 > 爆款复刻` 中粘贴 TikTok / 抖音 / 小红书视频链接，系统提取视频并自动填入 `参考视频`。
3. 用户 hover 已导入素材左上角信息图标，查看该素材来源平台及导入链接。
4. 用户输入的链接格式看起来像链接，但并非有效内容链接时，系统阻断并提示。
5. 用户链接校验通过，但提取链路异常时，系统在导入框下方展示红字错误，且保留原输入内容便于修改重试。

## 6. 功能清单

### 6.1 导入入口

在目标上传区下方新增导入链接条，包含：

1. 平台链接提示文案：`支持导入TikTok、抖音、小红书链接。`
2. 链接输入框。
3. `导入` 按钮。
4. “已获取内容授权”勾选项。
5. 提取异常时的红字错误提示区域。

### 6.2 授权勾选记忆

1. 用户首次手动勾选授权后，系统记住该状态。
2. 后续再次进入页面时，默认维持已勾选状态。
3. 若用户手动取消勾选，应同步清除记忆状态。

### 6.3 链接有效性校验

1. 点击 `导入` 后，必须先校验输入内容是否为有效内容链接。
2. 若为空，提示：`请先输入需要提取的链接`
3. 若不是有效内容链接，提示：`请输入有效的内容链接`
4. 链接校验未通过时，不进入授权校验与提取逻辑。

### 6.4 内容类型匹配校验

为避免“链接本身有效，但提取出的内容类型与上传位不匹配，最终无法上传”的问题，系统需在提取前增加内容类型匹配校验。

规则如下：

1. `set-replica` 的 `参考图` 上传位只允许导入图片内容链接。
2. `video-replica` 的 `参考视频` 上传位只允许导入视频内容链接。
3. 若链接内容类型与当前上传位不匹配，必须在提取前直接拦截，不进入提取和回填流程。
4. 类型不匹配时应给出明确错误提示，而不是等到上传失败后再报错。

错误提示文案：

1. `参考图仅支持导入图片内容链接`
2. `参考视频仅支持导入视频内容链接`

### 6.5 授权校验

1. 仅当链接有效时，才校验授权勾选状态。
2. 若未勾选，提示：`请先确认已获得链接内容使用授权`
3. 未勾选时，不进入提取逻辑。

### 6.6 提取成功回填

1. `set-replica`
   - 若链接内容为图片，则提取图片并回填到 `参考图`
   - 若链接内容为视频，则提取关键帧图片并回填到 `参考图`
2. `video-replica`
   - 提取视频并回填到 `参考视频`
3. 成功后提示成功 toast：
   - 图片场景：`已提取X个参考素材并填入上传框`
   - 视频场景：`已提取参考视频并填入上传框`
4. 成功后清空输入框内容。

### 6.7 提取失败处理

1. 若链接校验已通过，但提取过程中失败或发生异常：
   - 在导入条下方新增一行红字错误信息
   - 同时保留输入框内原链接，不清空
2. 错误信息来源于提取异常返回文案；若无明确异常文案，则使用兜底文案。

### 6.8 已导入素材来源标记

仅对“通过链接提取导入”的素材显示来源信息标记，不影响本地上传和资源库上传素材。

展示规则：

1. 素材卡片 hover 时，左上角显示 `i` 信息图标。
2. hover 信息图标时展开信息框。
3. 信息框展示两部分信息：
   - `来源：TikTok / 抖音 / 小红书`
   - `导入链接：<原始导入链接>`

### 6.9 信息框自适应定位

信息框展示时不得被可视区域裁剪。

定位原则：

1. 默认优先向右下展开。
2. 若右侧空间不足，则改为向左展开。
3. 若下方空间不足，则改为向上展开。
4. 若右下都不足，则使用左上方向。
5. 信息框容器不可被上传单元自身 `overflow` 裁剪。

## 7. 详细交互流程

### 7.1 爆款套图复刻 > 参考图

1. 用户在 `参考图` 上传区域下方看到导入链接条。
2. 输入 TikTok / 抖音 / 小红书内容链接。
3. 点击 `导入`。
4. 系统校验链接是否为有效内容链接。
5. 若链接有效，再校验内容类型是否与 `参考图` 上传位匹配。
6. 若类型匹配，再校验“已获取内容授权”是否勾选。
7. 校验通过后执行提取。
7. 提取成功：
   - 将提取图片或视频关键帧图片填入 `参考图`
   - 素材卡左上角支持查看来源信息
8. 提取失败：
   - 导入条下方显示红字错误
   - 输入框内容保留

### 7.2 视频创作 > 爆款复刻 > 参考视频

1. 用户在 `参考视频` 上传区域下方看到导入链接条。
2. 输入 TikTok / 抖音 / 小红书内容链接。
3. 点击 `导入`。
4. 系统先校验链接有效性。
5. 若链接有效，再校验内容类型是否与 `参考视频` 上传位匹配。
6. 若类型匹配，再检查授权状态。
7. 校验通过后执行视频提取。
6. 提取成功：
   - 视频填入 `参考视频`
   - 左上角支持查看来源信息
7. 提取失败：
   - 导入条下方显示红字错误
   - 原链接保留

## 8. 状态设计

### 8.1 导入条状态

| 状态 | 触发条件 | 表现 |
| --- | --- | --- |
| 默认 | 初始进入 | 输入框可编辑，按钮可点击 |
| 链接为空 | 点击导入且无输入 | toast 提示“请先输入需要提取的链接” |
| 链接无效 | 输入非有效内容链接 | toast 提示“请输入有效的内容链接” |
| 类型不匹配 | 链接有效但内容类型与上传位不匹配 | 提示对应类型错误文案，不进入提取 |
| 待授权 | 链接有效但未勾选授权 | toast 提示“请先确认已获得链接内容使用授权” |
| 提取中 | 已触发提取 | 按钮文案显示 `提取中`，按钮禁用 |
| 提取成功 | 提取并回填成功 | 输入框清空，toast 成功提示 |
| 提取失败 | 校验后提取失败 | 导入条下方显示红字错误，输入内容保留 |

### 8.2 素材卡来源标记状态

| 状态 | 触发条件 | 表现 |
| --- | --- | --- |
| 无标记 | 本地上传 / 资源库导入 | 不显示左上角 `i` 图标 |
| 可显示标记 | 链接导入素材，未 hover 卡片 | 默认隐藏 `i` 图标 |
| 展开标记 | hover 单个素材卡 | 显示左上角 `i` 图标 |
| 展开信息框 | hover / focus `i` 图标 | 显示来源信息框，自动调整方向 |

## 9. 校验规则

### 9.1 平台范围

仅支持：

1. TikTok
2. 抖音
3. 小红书

### 9.2 链接有效性规则

系统仅接受“平台内容链接”，不接受普通主页、无内容标识链接、无效文本。

示例判定思路：

1. TikTok：包含内容页、视频页、图文页、分享短链等内容标识。
2. 抖音：包含视频页、分享页、内容短链等内容标识。
3. 小红书：包含笔记页、内容详情页、分享短链等内容标识。

不符合上述内容语义的链接统一视为无效内容链接。

### 9.3 内容类型匹配规则

| 上传位 | 允许内容类型 | 不允许内容类型 | 错误提示 |
| --- | --- | --- | --- |
| 参考图 | 图片内容链接 | 视频内容链接 | `参考图仅支持导入图片内容链接` |
| 参考视频 | 视频内容链接 | 图片内容链接 | `参考视频仅支持导入视频内容链接` |

系统必须在提取前完成该校验，避免提取后因上传位限制导致回填失败。

### 9.4 输入清空规则

| 场景 | 是否清空输入框 |
| --- | --- |
| 链接为空 | 否 |
| 链接无效 | 否 |
| 未勾选授权 | 否 |
| 提取失败/异常 | 否 |
| 提取成功 | 是 |

### 9.5 授权记忆规则

1. 勾选授权后持久记忆。
2. 下次进入页面仍默认勾选。
3. 用户取消勾选后应同步更新记忆状态。

## 10. 异常处理

| 异常场景 | 处理方式 |
| --- | --- |
| 输入为空 | toast 提示“请先输入需要提取的链接” |
| 非有效内容链接 | toast 提示“请输入有效的内容链接” |
| 链接有效但内容类型不匹配 | 阻断提取并提示对应类型错误文案 |
| 有效链接但未授权 | toast 提示“请先确认已获得链接内容使用授权” |
| 平台支持但解析失败 | 导入条下方显示红字错误，且保留输入链接 |
| 提取过程异常 | 导入条下方显示异常错误，且保留输入链接 |
| 信息框展开空间不足 | 自动切换方向，确保尽量完整显示 |

## 13. 验收标准

### 13.1 功能验收

1. `set-replica` 与 `video-replica` 均出现导入链接条。
2. 仅支持 TikTok / 抖音 / 小红书有效内容链接。
3. 点击导入时，必须先校验链接，再检查授权勾选。
4. 点击导入时，若链接有效，还必须校验内容类型与当前上传位是否匹配。
5. `参考图` 不允许导入视频内容，`参考视频` 不允许导入图片内容。
6. 类型不匹配时必须在提取前拦截，不得出现“提取成功但无法上传”的情况。
7. 授权勾选一次后应被记忆。
8. 提取成功后素材自动回填至对应上传区域。
9. 链接导入素材左上角支持来源信息查看。
10. 来源仅显示平台名，不显示冗余说明。
11. 信息图标仅在 hover 单个素材卡片时出现。
12. 信息框能根据显示区域自动变换方向，尽量完整显示。
13. 信息框不会被上传单元局部裁剪。
14. 提取失败时，导入框下方出现红字错误提示。
15. 提取失败时输入框内容保留，不被清空。
16. 提取成功时输入框清空。

### 13.2 体验验收

1. 导入条视觉风格与当前上传区保持统一，接近轻量导入组件风格。
2. 来源信息图标不干扰主上传预览和删除操作。
3. 删除按钮仍保持原有右上角操作语义不变。
4. 错误提示位置稳定，不应遮挡输入框与按钮。

## 14. 待确认项

当前无阻断性交互待确认项。  
若后续接入真实后端提取服务，需要单独补充：

1. 各平台真实可解析链接格式白名单。

3. 视频提取与关键帧提取的真实数量策略。
4. 提取素材大小、时长、清晰度与计费规则。
